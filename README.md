# RAG Demo

A small, production-quality Retrieval-Augmented Generation (RAG) app. Upload
documents, ask natural-language questions, and get answers grounded in those
documents with citations back to the source chunks. When the documents don't
contain the answer, the app says so instead of guessing.

> Full documentation (architecture, design decisions, how to run/test) is filled
> in at the end of the build. This is the skeleton.
